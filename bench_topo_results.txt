Notes:
- Circuit under test: n-input XOR-reduction chain (n-1 XOR gates, depth n) --
  a worst-case shape for the greedy fixed-point loop (one full pass per depth
  level => O(G^2*W) per evaluation), the exact bottleneck described in #3.
- "greedy" is a byte-for-byte copy of the pre-#3 algorithm; "topo" is the new
  memoized topological-order evaluation (O(G+W) per evaluation after one
  cached O(G+W) Kahn build). Byte-identical outputs on all rows verified
  in-loop (verify_identical).
- Timings include the shared O(n * 2^n) input-scan loop, so the measured gap
  understates the pure per-evaluation gain.
- Scaling evidence: adding one input doubles the row count (2x) AND deepens
  the chain; greedy grows ~2.3-2.6x per step (superlinear), topo stays ~1-2x
  per step. At n=14 (16384 rows) topo is ~7x faster and the gap widens with n.

Before (#3 unshipped): every truth-table row re-scanned ALL wires for EVERY
un-evaluated gate on every pass -> worst case O(G^2*W) per row, no cached
ordering between calls.
After (#3 landed): Kahn topological order built once + invalidated on any
wiring/gate change; each row evaluates in a single O(G+W) topo pass.
